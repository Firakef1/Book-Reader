# BookReader

Local-first React Native reading app built with Expo. Resume where you left off, highlight passages, and customize themes and typography.

## Run

```bash
npm install
npm start
```

Then open in Expo Go (iOS/Android) or press `w` for web.

## Features (MVP)

- Smart resume with auto-save every 30 seconds
- Multi-book library with search, status filters, and sorting
- Paragraph highlights (5 colors) with export to clipboard
- Light / Dark / Sepia / Dark Sepia themes
- Font size, family, line height, alignment, letter spacing
- Reading stats (pages today, streak, session averages)
- Import `.pdf`, `.epub`, and `.txt` files (library starts empty; PDF prioritized)

See `docs/BookReader_PRD.md` for the product requirements and `docs/ADJUSTMENTS.md` for intentional deviations from the PRD.
